The name stands for Java Software Development Toolkit

This is not a commercial project, this is just something I find interesting and dedicate some free time to.

The goal of this project is to make GLFW, OpenGL, and FreeType bindings using the new Java Native API. 

The GLFW bindings are already usable and complete. 
The goal is to be able to use the API's just like you would in C for ease of use. 
This toolkit also contains Pointer abstraction utility classes that allow you to allocate memory like you would in C.
